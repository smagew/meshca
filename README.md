# meshca

Аналитика трафика сети MeshCore по данным собственного observer'а: кто сколько отправляет,
какие узлы ретранслируют, какие закономерности есть в активности сети.

Статус: пакеты собираются в PostgreSQL и разбираются (пути, справочник узлов, сообщения каналов). Панели Grafana
отвечают на вопросы «кто сколько шлёт» и «кто ретранслирует», показывают ритмы, изменения справочника и «кто с кем
общается». Узел за префиксом пути определяется расчётом с измеряемой точностью. Своя страница «Карта связей»
показывает, как пакеты идут к observer'у, на настоящей карте. Классы узлов и аномалии — после накопления данных.

- [docs/SPEC.md](docs/SPEC.md) — спецификация: данные, архитектура, алгоритмы, интерфейс, критерии приёмки.
- [docs/PLAN.md](docs/PLAN.md) — план работ по этапам.
- [docs/DEPLOY.md](docs/DEPLOY.md) — развёртывание, подключение observer'а, испытания, откат.

Главное ограничение: работу observer'а не трогаем. Проект только подписывается на его пакеты
и обрабатывает их отдельно. Всё работает в Docker.

## Состав

```
compose.yaml      стек Docker Compose: mosquitto, postgres, migrate, collector, worker, grafana
collector/        сборщик: MQTT → PostgreSQL, без разбора пакетов
migrate/          применение схемы базы (отдельный образ, чтобы новая миграция не перезапускала сборщик)
worker/           разбор пакетов и контроль сбора
grafana/          панели и источник данных как код
db/migrations/    схема базы
mosquitto/        настройки брокера и права пользователей
tests/            модульные тесты (pytest)
docs/             спецификация, план, инструкция
```
